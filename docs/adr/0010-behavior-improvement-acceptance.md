# ADR-0010: Behavior-improvement Acceptance, Not Reasoning-process Acceptance

- 状态: Accepted
- 日期: 2026-08
- 决策者: TSAgent 架构

---

## 背景

智能能力的常见验收陷阱是评估"推理过程"：CoT 是否合理、模型为什么这么想、prompt 是否"聪明"。
这些标准不可外部验证、不可回归，且会鼓励过度工程化推理链路而非改善行为。

## 决策

> **智能能力必须以行为改进为验收标准，而不是以推理过程为验收标准。**

具体含义：

- 不评估 Chain of Thought 写得好不好。
- 不评估模型为什么这么想。
- 只评估最终行为是否改善：计划是否覆盖目标、是否遵守约束、顺序是否正确、任务完成率是否提升。

与 v1.x 的统一：每一层都用**可验证的外部行为**作为质量标准，而不是内部实现细节。

```
Runtime    看行为（不会崩）
Resolver   看行为（不会误判）
Intelligence 看行为（决策是否更好）
```

## 后果

- 智能层 PR 的验收必须包含"行为指标对比"（before / after），否则不合并。
- 禁止以"prompt 更合理"作为交付理由；必须有行为数据支撑。

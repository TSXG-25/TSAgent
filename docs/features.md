本文给使用者看：TSAgent 现在能做什么、在哪里操作。功能状态的依据是代码和离线测试

## 1. 启动方式

| 方式 | 命令 | 说明 |
|---|---|---|
| 演示模式 | `cd apps/desktop && npm run dev` | 前端使用内存 Mock 数据，顶栏显示 `DEMO` |
| 浏览器 + 本地后端 | `.venv/bin/python -m agent.service.local_sidecar --http 8765`，再以 `VITE_AGENT_SERVICE_MODE=local` 启动前端 | 后端只监听 127.0.0.1，并校验 Host/Origin |
| 桌面应用（Tauri） | `npm run tauri:dev` | Tauri 通过 stdio 拉起 Python 后端；脚本已按包目录推导 `VITE_TSAGENT_SIDECAR_CWD=../..` 与 `VITE_TSAGENT_SIDECAR_CMD=../../.venv/bin/python`（项目 venv，含 playwright）。自定义解释器时改用 `npm run tauri dev` 并自行导出这两个变量 |
| 命令行 | `python main.py` | 不使用图形界面，直接调用 AgentService |

模型提供方：DeepSeek（OpenAI 兼容接口）或本地 Ollama。可在「全局设置」中切换。连接失败时先重试 3 次，
然后切到备用模型，每 60 秒探测一次原模型是否恢复。

## 2. Agent 能力（后端）

### 2.1 任务执行
- **自然语言任务**：输入一个请求后创建 Run。执行分四步：意图分析与授权 → 模型调用工具循环 → 校验目标与实际效果 → 完成。
- **原生工具调用**：只读和检索类工具最多 4 个并发；写文件、执行命令这类调用逐个执行；结果按模型给出的顺序写入。
- **流式输出**：回复边生成边显示，完成后改为显示已持久化的最终结果。
- **完成声明需要证据**：只有对应的文件、执行结果或产物确实存在，Run 才会标为完成。不会把"模型说做完了"当作完成。

### 2.2 内置工具
| 类别 | 工具 |
|---|---|
| 文件 | 读取、写入、复制、移动、删除、列目录、查找；补丁的提议与应用 |
| 代码执行 | Python（含在工作区内运行）、Shell（需要授权） |
| 办公文档 | 生成和编辑 pptx / docx，生成 xlsx |
| 网络 | 网页搜索、新闻搜索、深度搜索、网页抓取（DuckDuckGo，失败时改用 DeepSeek） |
| 记忆 | 查询记忆、读取用户偏好、保存事实、长期知识检索（`reme_search`） |
| 编排 | 按需加载技能（`load_skill`）、调用工作流（`run_workflow`）、派生子任务（`spawn_subtask`） |
| 扩展 | MCP 客户端（DuckDuckGo、ReMe、Bilibili 等服务） |

内置技能：`coding`、`research`、`code-animation-prompts`（位于 `skills/`，用到时才加载）。

### 2.3 可靠性
- **持久化**：Run、事件、产物、会话都存在 SQLite 中，默认路径 `~/.tsagent/runtime.db`。
- **崩溃恢复**：进程重启后，可以从 checkpoint 精确恢复同一个工作流，已完成的阶段不会重复执行。
- **取消与超时**：状态依次为 `ACTIVE → CANCELLING → CANCELLED`；超时后为 `TIMED_OUT`。中途终止时，已验证的部分产物会保留。
- **暂停 / 恢复**：Run 可以暂停；处于 `BLOCKED` 状态且满足恢复条件时，可以恢复执行。
- **防止重复执行**：同一会话同时只能有一个活跃 Run；后端进程意外退出后，Run 会被标记为 `RUN_WORKER_LOST`。
- **失败处理**：只读类或确定没有副作用的失败，会在限定次数内重新规划；副作用不确定时不会自动重放。

### 2.4 记忆
- **持久事实**：写入前按敏感信息、密钥、遗忘请求等规则过滤。`scope="user"` 的事实可以在同一用户的不同会话间共享。
- **长期知识**（ReMe）：每轮对话结束后在后台提炼知识，支持 BM25 和双链检索；服务不可用时跳过，不影响任务执行。

### 2.5 审批
需要授权的动作会生成审批单，显示动作、目标范围、风险等级和参数。批准或拒绝后 Run 继续执行或停止。

## 3. 桌面工作台（前端）

入口是星图：太阳加九颗行星，每颗对应一个工作台。用 `⌘0`–`⌘9` 或顶栏的星球切换器（支持搜索和最近访问）直接跳转。

**每个工作台各自独立**：有自己的当前会话，可以绑定自己的目录，任务归属记在该工作台名下。
几个工作台可以绑定同一个目录，这时文件是共享的，但任务和会话仍然分开。

### 全局功能
- **新建任务** `⌘N`：在哪个工作台按下，任务就归哪个工作台。
- **Agent Dock** `⌘L`：在任意工作台打开对话抽屉，使用该工作台的会话。
- **任务托盘**：所有进行中的任务和待处理审批集中显示，点击可跳到对应的 Run。
- **全局设置**：模型与 Provider、Profile、技能、工作区目录、界面语言（中文 / English）。
- **输入**：Enter 发送，Shift+Enter 换行，输入法组合输入时按 Enter 不会发送；草稿按会话保存，切换页面不会丢失。
- **消息显示**：渲染 Markdown（表格、代码高亮、代码块一键复制）；向上翻看历史时不会被新消息拉回底部。
- **错误提示**：后端出错时显示本地化的说明，并附原始错误码。不会悄悄切换到 Mock 数据。

### 各工作台

| 工作台 | 名称 | 已实现 |
|---|---|---|
| ☉ Sun | Omni | 跨工作台总览：会话列表（按工作台筛选、按文件夹分组、拖动归类、置顶）、对话线程、执行过程链（文件、搜索、命令分类显示）、审批卡片、产物（预览、复制引用、在访达中显示）、失败后恢复 |
| ☿ Mercury | Navigator | 网页搜索，显示结果和来源链接（不包含浏览器接管） |
| ♀ Venus | Muse | 预览 md、txt、svg 文档；生成内容时套用 `style.md` 风格和预设 |
| ⊕ Earth | 有机智能实验室 | 设置生物代理参数，人工评判，查看评测记录；可对照已提交参数与当前参数 |
| ♂ Mars | Forge | 工程工作台：内嵌 code-server IDE（由应用托管，跟随绑定目录），工作区文件读写，可把 IDE 中当前打开的文件作为任务上下文发送 |
| ♃ Jupiter | Archive | 文件和产物检索，记忆与历史回放，删除记忆（forget），预览产物 |
| ♄ Saturn | Chronos | 定时任务：创建、暂停、重试，显示下次触发时间和最近一次执行的 Run |
| ⛢ Uranus | Laboratory | 工作流节点图的编辑、保存和运行（上游节点的产物传给下游），查看节点执行状态并跳到对应的子 Run |
| ♆ Neptune | Media Studio | 媒体画布、素材索引、SVG 预览，委派生成媒体 |
| ♇ Pluto | Genesis | 母题管理：候选、证据、人工裁决（报告、驳回、确认）；确认后写入记忆并附证据链接 |

**跨工作台委派**：工作台之间可以互相委派任务，例如 Uranus 委派给 Neptune。子任务会出现在目标工作台，结果回到发起的工作台。
委派默认使用父任务的目录，界面上会标明。

## 4. 未在真实环境验收

以下功能代码已完成，离线测试也已通过，但还没有在真实环境中实际操作验证：

- 十个工作台在浏览器和 Tauri WebView 中的实际布局、焦点、Esc 键和中英文切换；
- Tauri 应用中 Mars 内嵌 IDE 的启动和停止，以及终端、快捷键、剪贴板；切换目录、离开页面、退出应用时 IDE 进程是否正确结束；
- Mercury 使用真实搜索服务的效果，以及在 WKWebView 中能否用外部浏览器打开链接；
- Neptune 真实媒体生成（需要 ffmpeg 和可用的模型）；
- 真实模型下的崩溃恢复、prompt 注入防护评估；
- 在干净机器上安装 Tauri 应用后的进程生命周期。

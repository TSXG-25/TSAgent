# TSAgent 星球工作台 UI 设计 v1.0

**定位**：本文取代 Implementation Plan v1.0 §6 / §8 和 `apps/desktop/design.md` 中关于版式、视觉的规定。功能契约（Task / Run / Handoff / Approval / Artifact、权限、审批）不变。
**优先级**：功能 > 美观。保留现有风格：中性黑底、细线分隔、单一主题色焦点、机甲切角、Borda 标题。
**依据**：2026-11-05 以 mock 模式在 1600×960 下对 `/#/` 与 `/#/w/:scene` 共 11 张截图，以及 `apps/desktop/src` 当前源码。

## 2. 设计原则

1. **一屏一主对象**。每个工作台只有一个主对象，占 ≥55% 的画布宽度；其余区域只服务它。
2. **星体特性 → 一个有功能的标志元素**。每颗星球只有一个标志元素，它必须同时承担功能（时间轴、对照、版本滑轨…），不做纯装饰。
3. **面板按内容高度**。没有内容就显示带操作的空态，不拉伸空框。
4. **一个输入入口**。全局对话只在 Agent Dock（§3.3）；页内输入只用于本星球原生操作（URL、检索、表单）。
5. **状态不只靠颜色**。所有状态 = 图形 + 文字；主题色从不表达状态。
6. **不伪造**。未安装能力显示在它本该出现的位置，一行说明；演示数据必须带 `DEMO` 标签。

## 3. 全局骨架

### 3.1 单行顶栏（44px，取代 topbar + ws-head）

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ✦ T.S.A  ▸  ♂ Forge ▾        ● run-2048  ACTIVE 62%   ⛨ 2   ⚙   ◎ 星图 │
└──────────────────────────────────────────────────────────────────────────┘
   品牌     星球切换器          当前 Run 状态胶囊      审批  设置  返回星图
```

- **星球切换器**：下拉列出 10 个场景（星球符号 + 主题色点 + 名称 + 该星球进行中 Run 数）。快捷键 `⌘0` = Sun，`⌘1–9` = 水星…冥王星。不必回星图就能切换。
- **Run 胶囊**：显示当前 Run 的 id、状态、进度；点击展开 Task Tray。
- **审批**：盾牌 + 数字；有 R2 及以上待审批时数字填充 danger 色。
- **数据源**：mock 模式时，品牌旁出现 `DEMO` 标签（实心、主色），而不是一个灰色的 "Mock AgentService"。
- 星球主题色只出现在：切换器里的当前星球符号、顶栏底部 1px 主题色线。

### 3.2 工作台画布

- 顶栏下方即画布，四周 12px 外边距，面板间距 12px。
- 没有工作台标题栏：星球名已经在切换器里。
- 每个工作台自己定义栅格（§5），不再共用 `cols-3`。
- 可调宽度的列使用现有 `EdgeResizer`；宽度按 `workspace:{planet}:layout` 持久化。

### 3.3 Agent Dock（取代每页底部 composer 和浮动 GlobalChat）

| 状态 | 外观 | 何时 |
|---|---|---|
| 收起 | 顶栏右侧 `@forge ⌘L` 小胶囊 | 默认（除 Sun、Mars） |
| 抽屉 | 右侧 380px 抽屉，覆盖在右栏上方，玻璃材质 | `⌘L` |
| 嵌入 | 作为工作台的一列 | Sun（中栏）、Mars（右栏） |

Dock 内容自上而下：会话选择 → 消息流（Message / Event / Artifact / Approval 四种卡片分开渲染）→ 上下文胶囊（当前文件、选区、Artifact，可逐个移除）→ 输入框（`@` 唤起星球选择器）。

- 委派后，消息流里出现一张委派卡：目标星球、子任务 id、状态，结果回流时原地更新。
- 页内原生输入（Mercury 地址 / 检索、Jupiter 检索、Saturn 新建计划）**不经过** Dock。
- 上下文胶囊依赖 Handoff 的 `contextRefs`；当前 `delegateToPlanet` 只传文本，接上之前胶囊不显示。

### 3.4 状态语义

| 状态 | 图形 | 文字 | 颜色 |
|---|---|---|---|
| active / running | ● 呼吸点 | ACTIVE | `--st-live` |
| completed / verified | ✓ | DONE / VERIFIED | `--st-ok` |
| blocked / waiting_approval | ⏸ | BLOCKED | `--st-warn` |
| paused | ‖ | PAUSED | `--text-muted` |
| failed / timed_out | ✕ / ⌛ | FAILED / TIMED OUT | `--st-danger` |
| cancelled | ⊘ | CANCELLED | `--text-muted` |
| queued / pending | ○ | QUEUED | `--text-faint` |

**主题色冲突处理**：在 Mars / Saturn / Earth 中，主题色只用于结构标记（选中条、tab 下划线、焦点环），从不出现在 chip 或文字上；状态 chip 永远带图形，所以即使颜色接近也能区分。

## 4. 视觉系统（保留风格的修订）

### 4.1 色彩

```css
:root {
  --bg-root:    #0d0e11;   /* 保留 */
  --surface-1:  #13151a;   /* 面板（实色，取代工作台内的玻璃面板） */
  --surface-2:  #1a1d23;   /* 输入框、悬停行、嵌套卡片 */
  --surface-3:  #22262e;   /* 选中行、按下 */
  --glass:      rgba(19,21,26,.72); /* 只用于浮层：Dock 抽屉、弹出、星图 HUD */

  --line:        rgba(255,255,255,.08);
  --line-strong: rgba(255,255,255,.16);

  --text-main:  #eef1f4;
  --text-muted: rgba(255,255,255,.64); /* 原 .55，提升对比 */
  --text-faint: rgba(255,255,255,.42); /* 原 .32 在面板上不足 3:1 */

  --st-live:   #5ad1ff;
  --st-ok:     #4cc38a;
  --st-warn:   #f0b429;
  --st-danger: #ff5a4f;
}
```

- 工作台面板改为实色 `--surface-1`：黑底上的模糊玻璃没有可见收益，反而降低对比、增加 GPU 负担。玻璃只留给浮层，这样"浮在上面"的层级才有意义。
- 主题色派生（每星球自动计算，不手写）：
  `--accent`、`--accent-line: color-mix(in srgb, var(--accent) 55%, transparent)`、`--accent-fill: color-mix(in srgb, var(--accent) 12%, transparent)`、`--accent-ink: #0d0e11`（实心按钮上的文字）。

### 4.2 字体

| 角色 | 字体 | 字号 / 行高 | 用途 |
|---|---|---|---|
| 展示 | Borda 600 | 18 / 24、24 / 30 | 切换器中的星球名、Run 标题、大数字 |
| 标签 / 状态 / 数字 | Rajdhani 600 | 12 / 16（不小于 12） | 面板标题、状态 chip、表头、tabular 数字 |
| 正文（中英） | HarmonyOS Sans SC | 13 / 20 | 消息、描述、表单、列表正文 |
| 阅读（Venus、Pluto 报告） | 思源宋体 Source Han Serif SC | 16 / 28，≤ 68ch | 长文 |
| 等宽 | JetBrains Mono | 12 / 18 | 代码、路径、id、哈希 |

- Rajdhani 是窄体，12px 以下的正文和中文混排里可读性差，所以只用于标签和数字，保留机甲感。
- 字体全部本地打包为 woff2（Tauri 离线），打包前确认许可。
- 去掉所有宽字距的大写按钮文字；大写只用于状态 chip。

### 4.3 密度档

| 档 | 行高 | 面板内边距 | 星球 |
|---|---|---|---|
| compact | 28px | 10px | Mars、Mercury（轨迹）、Jupiter、Saturn |
| regular | 36px | 14px | Sun、Earth、Uranus、Neptune |
| comfortable | 44px | 20px | Venus、Pluto |

### 4.4 组件

- **Panel**：`--surface-1`，1px `--line`，圆角 4px；只有一级面板保留右下 10px 切角（机甲标识）。标题栏 36px：Rajdhani 600 12px 标题 + 右侧计数 / 操作。高度随内容。
- **Button**
  - Primary：实心 `--accent`，文字 `--accent-ink`。每个视图最多一个。
  - Secondary：1px `--line-strong`，透明底，悬停 `--surface-2`。
  - Ghost：无边框，用于行内操作。
  - Danger：红色描边；不可逆操作（Delete、Forget）弹出确认，确认按钮为实心红。
  - 高度 28 / 32px，sentence case。
- **Form**：label 在控件上方（12px muted）；控件满宽；select 用 `appearance:none` + 自绘箭头；checkbox / toggle 自绘；焦点 = 2px `--accent-line` 外环。
- **Status chip**：图形 + 大写文字，20px 高，1px 状态色描边 + 10% 状态色填充。
- **Table**：同类记录列表一律用表格（Saturn 计划、Jupiter 结果、Earth 判决、Memory），列对齐，表头 sticky，不再用"卡片 + 一串 meta 文本"。
- **Empty state**：放在内容区视觉中心：星球标志纹样（§4.5，低亮）+ 一句说明 + 一个操作按钮。
- **Not installed**：一行内联提示，出现在能力本该出现的位置（比如 tab 内容区、视口内），不再用占据主面板的大虚线框。

### 4.5 背景与星球纹样

- 删除 fractalNoise 噪声和网格背景，删除 3 份重复的 `.ws-root::before`，只保留一份。
- 画布底色为平的 `--bg-root`。
- 星球纹样（SVG，`--accent` 4–6% 不透明度）只出现在两处：顶栏中当前星球名后方 120px 区域，以及空态插图。这样星球个性出现在有空间的地方，不压正文。
- 呼吸：只作用于纹样不透明度，周期 9s；`prefers-reduced-motion` 或"低特效"设置下关闭。

| 星球 | 纹样 |
|---|---|
| Sun | 放射日冕细线 |
| Mercury | 水平速度线 |
| Venus | 柔和云带 |
| Earth | 双圆（地月轨道） |
| Mars | 等高线（奥林帕斯山地形） |
| Jupiter | 水平条带 + 一个椭圆斑 |
| Saturn | 一条侧视光环细线 |
| Uranus | 旋转 98° 的轴线网格 |
| Neptune | 深场等压波纹 |
| Pluto | 稀疏点阵（柯伊伯带） |

### 4.6 动效

- 删除所有面板的 `perspective / rotateY` 倾斜。
- 删除列表行悬停 `translateY(-1px)`：密集列表里会抖动。
- 抽屉打开 180ms ease-out，关闭 140ms；tab 下划线 150ms；状态变化时 chip 闪一次 200ms。
- 自定义光标只在星图生效，进入工作台恢复系统光标。

### 5.1 ☉ Sun / Omni

**星体特性**：系统质心，所有行星绕它运行，光由它发出。
**功能转译**：唯一以对话为中心的工作台；所有被委派的子任务都"绕"着当前任务显示。
**主对象**：当前 Run 的对话 + 它的任务树。

```
├────────────┬─────────────────────────────────────────┬──────────────────┤
│ Runs  ⌕    │ run-2048  ⏸ BLOCKED          [Resume] ⋯ │ [Tree][Exec]     │
│ session ▾  │ 生成一个 Python 程序，计算 7 的平方并保存   │ [Events][Files]  │
│            │ workflow code-gen-v2 · 62% · cp-123 · 03:14│                  │
│ ● run-2048 │ ┄ 轨道条 ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ │ ⛨ 待审批 1       │
│   生成一个…│  ☿ research ✓   ♂ impl ●   ♀ doc ○        │ R1 file.write    │
│ ✓ run-2047 │ ┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄┄ │ [Approve once]   │
│ ● run-2044 │                                          │ [Deny] [Inspect] │
│ ⌛ run-2039 │  You  09:41                              │ ──────────────── │
│ ✕ run-2041 │  生成一个 Python 程序…                    │ task-2048        │
│            │  T.S.A  09:42                            │ ├ ☿ sub-research │
│            │  ▣ Artifact  output/solution.py  ✓       │ └ ♂ impl  ●      │
│            │  ⚙ Event     verifier waiting            │                  │
│            │ ┌──────────────────────────────────────┐ │                  │
│            │ │ @ 委派…   [solution.py ×]          ➤ │ │                  │
│            │ └──────────────────────────────────────┘ │                  │
├ 240px ─────┴────────────── flex ────────────────────┴ 320px ───────────┤
```

**关键交互**
- 轨道条：只有当前任务存在子任务时才出现。每个子任务一个胶囊（星球符号 + 简称 + 状态图形）；点击 → 右栏任务树高亮；双击 → 跳到对应星球并定位到该 Run。
- 待审批永远固定在右栏顶部，因为它会阻塞执行；没有审批时这块不出现。
- `⌘N` 新任务直接聚焦中栏输入框，不再弹模态框。
- Pause / Cancel / Resume 合并到 Run 标题行右侧：一个主按钮（按状态变化）+ `⋯` 菜单。

**数据来源**：`listRuns`、`getRun`、`readEvents`、`listTasks`、`listHandoffs`、`listApprovals`、`decideApproval`、`pauseRun` / `cancelRun` / `resumeRun`、`delegateRun`。

**相对现状**
- 删除 Sessions 面板（与左栏重复）→ 会话变成左栏顶部的筛选下拉。
- 删除 context-strip → 并入标题下的一行 meta。
- 删除 Delegate 表单 → 用输入框里的 `@` 委派。
- Execution（阶段列表、Verifier）移到右栏 tab。
- 删除页脚 `contract-driven console` 标语。

### 5.2 ☿ Mercury / Navigator

**星体特性**：离太阳最近、公转最快（88 天），信使；几乎没有大气。
**功能转译**：速度与实时监督。"无大气"= 视口上不叠任何玻璃或装饰，看到的就是 Agent 看到的。
**主对象**：浏览器视口。BrowserContext 未接入之前，主对象是检索结果。

```
├──────────────────────────────────────────────────────────┬──────────────┤
│ ◀ ▶ ⟳ │ https://docs.example.com/api/limits │ ● LIVE    │ 计划步骤      │
│ ┌──────────────────────────────────────────────────────┐ │ 1 navigate ✓ │
│ │                                                      │ │ 2 click    ✓ │
│ │            视口（截图 / 实时画面）                     │ │ 3 extract  ● │
│ │                                                      │ │ 4 summarize○ │
```

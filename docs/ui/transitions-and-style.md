# TSAgent 转场与"在轨作业"视觉升级 v1.0

**承接**：`planet-workspace-ui.md`（版式与功能）。本文只管两件事：**转场（motion）** 和 **科技感 / 帅 / 有趣**。
**可运行原型**：`docs/ui/motion-prototype.html`。需要从仓库根目录起一个静态服务（字体走相对路径，`file://` 会被浏览器拦截）：

```bash
cd TSAgent && python3 -m http.server 5299 --bind 127.0.0.1
# 打开 http://127.0.0.1:5299/docs/ui/motion-prototype.html
```

原型左下角可以切换特效档位（全效 / 标准 / 极简）和 **4× 慢放**。转场的手感以慢放 + 正常速度各看一遍为准。原型里的数据都是 DEMO。

---

## 1. 为什么现在"不够帅"

| 现象 | 证据 | 根因 |
|---|---|---|
| 进入工作台是硬切 | `MissionControl.tsx:116` `enterScene` 只调用 `navigate()` | 3D 星图里的镜头、辉光、冲击波 shader（`SolarScene.ts:270` `distortUniforms`）完全没参与进入工作台 |
| 星图和工作台像两个产品 | 星图有深空、辉光、轨道；工作台是灰色方框 | 两者之间没有任何视觉延续 |
| 界面"死"的 | 运行中、完成、等待审批，在视觉上只差一个文字标签 | 光和动效没有用来表达状态 |
| 装饰性的科技感（噪声、网格、3D 倾斜）反而显得廉价 | 前一份文档 D3 / D10 | 科技感来自装饰，而不是来自"仪器在工作" |

**结论**：科技感不靠加纹理，而靠三件事——**空间连续**、**光代表运行**、**仪器式的精确反馈**。

## 2. 概念：在轨作业（On-orbit operations）

> 你不是打开了一个网页，而是从星图切入了某颗星球的轨道，在轨道站里工作。

三条支柱，每条都同时承担功能：

1. **一镜到底**：星图 → 镜头推进 → 冲击波 → 揭幕 → 工作台。工作台底部的"轨道地平线"就是镜头停下的位置。空间连续 = 用户知道自己在哪、从哪来。
2. **发光 = 正在运行**：默认一切都是哑光的。只有正在运行、正在流式输出、等你处理的东西会发光。画面安静 = 没有事情在发生。
3. **锁定语言**：四角括号 ⌜⌟ = "锁定 / 聚焦"。星图锁定行星、面板获得焦点、预览选中对象，用的是同一套括号。它和现有自定义光标（`Cursor.tsx` 的 `cr-frame`）是同一语汇。

## 3. 动效 tokens

在 `tokens.css` 中补充（代码库里已有 `cubic-bezier(0.23,1,0.32,1)` 被散写 5 次，统一收进 token）：

```css
:root {
  --ease-out:    cubic-bezier(0.23, 1, 0.32, 1);    /* 进入 / 退出 */
  --ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);   /* 屏幕内移动（镜头、指示条） */
  --ease-drawer: cubic-bezier(0.32, 0.72, 0, 1);    /* 抽屉 */

  --dur-press: 100ms;   /* 按下反馈 */
  --dur-hover: 120ms;   /* 悬停颜色 */
  --dur-pop:   180ms;   /* 弹层、标签切换、列表插入 */
  --dur-drawer: 240ms;  /* 抽屉打开；关闭 200ms */
  --dur-reveal: 360ms;  /* 揭幕 */
}
```

规则：
- UI 交互一律 ≤ 300ms；只有"进入工作台"和"开机"这两个低频时刻可以更长。
- 不用 `ease-in`；不用 `transition: all`；不从 `scale(0)` 出现；只动 `transform`、`opacity`、`clip-path`。
- 键盘触发的高频操作（`⌘0–9` 切星球、`⌘K`、`⌘L`）**不做动画**。

## 4. 转场设计

### 4.1 总表

| # | 转场 | 频率 | 目的 | 时长 | 档位差异 |
|---|---|---|---|---|---|
| T0 | 开机（星图点亮） | 每次启动 1 次 | 愉悦 | 1.3s，可跳过 | 极简：直接显示 |
| T1 | 星图 → 工作台（轨道切入） | 偶尔 | 空间连续 | ≈ 600ms 揭幕 + 面板上线 | 标准：只保留揭幕；极简：150ms 淡入 |
| T2 | 工作台 → 星图（离轨） | 偶尔 | 空间连续 | 300ms 收拢 + 420ms 拉远 | 同上 |
| T3 | 工作台 ↔ 工作台（切换器） | 很频繁 | 防止跳变 | 键盘 0ms；鼠标 120ms 淡入 | — |
| T4 | 委派跳转（Sun 轨道条 → 某星球） | 偶尔 | 告诉用户落在哪 | T3 + 目标行 900ms 高亮渐隐 | — |
| T5 | Agent Dock 抽屉 | 每天几十次 | 空间连续 | 点击 240ms 开 / 200ms 关；`⌘L` 0ms | — |
| T6 | 审批托盘 / 弹层 | 偶尔 | 来源 | 180ms，从按钮方向展开 | 极简：无 |
| T7 | Tab 指示条 | 频繁 | 状态 | 180ms `--ease-in-out` | — |
| T8 | 新事件插入列表 | 持续 | 状态 | 180ms 进入 + 900ms 主题色底渐隐 | 极简：无 |
| T9 | 状态变化（→ DONE / FAILED / BLOCKED） | 偶尔 | 状态 | chip 换色 150ms + 一次 400ms 外扩环 | 极简：只换色 |
| T10 | 遥测数字变化 | 持续 | 状态 | 160ms 滚动 | 极简：无 |
| T11 | 高风险审批（R2+）按住确认 | 偶尔 | 防误触 | 按住 1.2s 线性填充；松手 200ms 回退 | — |
| T12 | 加载 | 偶尔 | 状态 | 超过 300ms 才出现扫描线，1.2s 线性循环 | 极简：静态文字 |

### 4.2 T1 轨道切入（核心转场）

时间轴（全效档，t = 0 是按下"进入工作台"/ ⏎ 的瞬间）：

```
t(ms)   0      120    220  240          420        600          900
        │──────┼──────┼────┼────────────┼──────────┼────────────┤
镜头推进 ████████████████████████████████          (320ms, ease-in-out, 距离 → 行星半径 × 3)
冲击波          ██████████████████████            (现有 uWave shader, 480ms; 第二道淡环 +70ms)
辉光/色散 ▁▂▃▅▆█████████▆▅▃                       (bloom 0.55 → 1.4, uIntensity 0 → 1)
闪变                   ▃█▅▂                        (主题色径向光, 峰值 0.6, 300ms, screen 混合)
呼号读数               ▂▅██████▅▂                  (FORGE · MARS 1.524 AU · 687 d，被揭幕圆吞没)
揭幕                         ████████████████      (clip-path 圆从行星屏幕坐标展开, 360ms ease-out)
面板上线                          ▂▅████████████   (首次进入: 逐个 50ms 错峰, 260ms, 每块一道扫描线)
地平线升起                        ▂▅███████████    (轨道地平线 translateY 40→0, 520ms)
WebGL 停止                                     ●  (揭幕结束即停止渲染循环 / 卸载)
```

要点：
- **路由立即切换**（t = 0 就 `navigate`），工作台在揭幕圆下面挂载并开始拉数据。转场本身就是加载遮罩，不增加等待。
- 揭幕结束前，星图图层必须保持挂载。实现：App 持有 `transition` 状态，存在时继续渲染 `MissionControl`，揭幕的 `finished` 后再卸载。
- **呼号读数和冲击波在工作台图层下面**，揭幕圆扫过时把它们"吞掉"，不会压在内容上。
- 面板上线只在本次会话第一次进入某星球时播放；再次进入只有揭幕。
- 转场期间任意按键 / 点击 = 立即跳到结尾（所有有限动画 `finish()`）。
- 首个输入焦点在揭幕结束时落位，不被动画打断。
- 揭幕圆心 = 行星在推进后的屏幕坐标（从 `SolarScene` 投影得到）；半径 = 圆心到最远角的距离。

实现映射：

| 环节 | 位置 | 做法 |
|---|---|---|
| 镜头推进 | `SolarScene.ts` | 新增 `insertion(key)`：设置目标 pose（距离 = 行星半径 × 3），复用 `targetPose()` 的指数插值，时间常数改为 0.12s |
| 冲击波 + 色散 | `SolarScene.ts:270` `distortUniforms` | `uCenter` = 行星屏幕坐标，`uWave` 0 → 1.2，`uIntensity` 0 → 1 → 0 |
| 辉光 | `bloomPass.strength` | 0.55 → 1.4 → 回落 |
| 闪变 / 呼号 / 揭幕 | 新增 `app/TransitionLayer.tsx` | WAAPI；`clip-path: circle()` 作用在工作台根节点 |
| 面板上线 | `WorkspaceFrame` | 首次进入时给 `.mp` 加 `data-boot`，WAAPI 错峰 |
| 音效 | `solar/sound.ts` | 新增 `insert()`：低频下滑 + 高频短促确认音；跟随现有开关 |
| 停止渲染 | `SolarScene` | 揭幕 `finished` 后 `dispose()`（与现在离开路由时的行为一致） |

### 4.3 T2 离轨

- 工作台用 `clip-path` 圆收拢到行星屏幕坐标，300ms `--ease-out`。
- 星图从近距离位姿开始，420ms `--ease-in-out` 拉回到用户离开前的位姿（`sessionStorage tsa.selector` 已在保存锁定状态，再加上镜头位姿）。
- 返回后行星保持锁定、时间保持冻结，用户看到"刚才在这里"。
- 离轨比切入短：用户已经决定离开，不再表演。

### 4.4 T3 工作台切换

- 键盘（`⌘0–9`）：0ms。这是高频操作，任何动画都会变成阻力。
- 鼠标点切换器：内容区 120ms 淡入；轨道地平线 200ms 交叉淡化。
- 顶栏 1px 主题色线和切换器中的星球符号颜色 200ms 过渡。这是唯一的身份变化提示。
- 不播放面板上线、不播放冲击波。

### 4.5 其他关键转场的规格

```css
/* T5 Dock：点击打开有动画，⌘L 打开时先加 .instant */
.dock { transform: translateX(100%); transition: transform 200ms var(--ease-drawer); }
.dock.open { transform: none; transition-duration: 240ms; }
.dock.instant { transition: none; }

/* T7 Tab 指示条：只动 transform */
.tabs .ind { width: 1px; transform-origin: left;
  transition: transform 180ms var(--ease-in-out); } /* translateX(left) scaleX(width) */

/* T11 按住确认 */
.hold::after { clip-path: inset(0 100% 0 0); transition: clip-path 200ms var(--ease-out); }
.hold.holding::after { clip-path: inset(0); transition: clip-path 1200ms linear; }
/* transitionend 只认 e.pseudoElement === "::after" */
```

- T8 事件插入：先 `opacity 0 / translateY(-4px)` → 原位 180ms；同时背景从 `--accent` 20% 渐隐到透明 900ms。首屏批量加载最多错峰 6 条（30ms），其余直接出现。
- T9 状态 ping：chip 内插入一个与 chip 同形的描边，`scale 1 → 1.6`、`opacity .7 → 0`，400ms，只在进入终态或 BLOCKED 时出现一次。

### 4.6 T0 开机

一次启动只播一次，点击 / 按键可跳过：
1. 星点按亮度淡入（0 → 600ms）。
2. 轨道由内向外画出，每条错峰 70ms（`ctx.ellipse` 的终止角 / 3D 中 `LineDashedMaterial` 的 `dashOffset`）。
3. 每条轨道画完后，该行星"点燃"。
4. 最后 HUD 出现。

## 5. 风格升级（S1–S8）

### S1 冷黑蓝底

把前一份文档里中性的 `#0d0e11` 体系偏冷，与 3D 深空一致：

| Token | 原 | 新 |
|---|---|---|
| `--bg-root` | `#0d0e11` | `#0a0d12` |
| `--surface-1` | `#13151a` | `#10141b` |
| `--surface-2` | `#1a1d23` | `#161b24` |
| `--surface-3` | `#22262e` | `#1d2430` |
| `--line` | `rgba(255,255,255,.08)` | `rgba(150,180,255,.09)` |
| `--line-strong` | `rgba(255,255,255,.16)` | `rgba(150,180,255,.18)` |

### S2 轨道地平线（每颗星球的标志画面）

- 工作台底部是一段巨大的行星边缘弧（3200px 圆，只露出顶部约 150px），带主题色大气辉光。它就是 T1 镜头停下的位置。
- 星球表面用 CSS 渐变绘制，不需要图片：木星的条带 + 大红斑、土星的条带 + 一条横穿的光环线、金星的云带、海王星深蓝、冥王星的心形亮区……
- 规则：在面板后面（面板是实色），只在缝隙、底部留白和空态区域可见；亮度 ≤ 60%；呼吸只在全效档，周期 9s，只动外层辉光的 opacity。
- 低特效 / 减少动态：静止。

### S3 发光 = 正在运行

| 对象 | 发光方式 |
|---|---|
| 正在运行的 Run 卡片 / 行 | 沿边框流动的主题色光（`conic-gradient` + mask，2.4s 线性循环）。同屏只允许一处 |
| 流式输出的消息 | 末尾闪烁的方块光标 ▍（1s steps） |
| 正在执行的步骤 / 计划 | 呼吸点 ● |
| 主按钮悬停 | 主题色外发光 |
| 聚焦面板 | 四角括号 + 标题左侧 2px 主题色刻度 |
| 其他一切 | 哑光，无阴影、无辉光 |

Run 结束时：流光停止，chip 执行一次 T9 ping。"光灭了" = 完成。

### S4 锁定语言

- 星图锁定行星：括号以 `scale(1.35) rotate(-45°)` → 原位，200ms `--ease-out`。这是锁定的"咔哒"感。
- 面板聚焦（`:focus-within`）：四角括号 `scale(1.03)` → 原位、淡入，140ms。
- 预览中的选中对象（Jupiter 详情、Neptune 画布选区）：同样的括号。
- 不在静态状态下到处画括号：括号只出现在"被锁定"的那一个对象上。

### S5 仪器遥测

- 顶栏右侧：`RTT 38ms`（sidecar health 往返）、`EVT #0172`（事件游标）、`LIVE 1`（运行中 Run 数）。Rajdhani tabular 数字；变化时 160ms 竖向滚动。
- **只显示真实数字**：RTT 来自 `health` 调用计时，事件游标来自 `readEvents` 的 `sequence_number`，运行数来自 Run 列表。没有数据源的指标不显示。
- 面板标题右侧的 meta（等宽 11px）同样只放真实值：Mars 的 `Ln 3, Col 12`，Saturn 的当前时刻和倒计时，Jupiter 的 `rev 1`。

### S6 字体当作仪器

- 进入工作台时的呼号读数：Borda 44px、字距 .14em、主题色 text-shadow，下面一行是来自 `orbits.ts` 的真实轨道参数（半长轴 AU、公转周期）。
- 空态背景：Borda 160px 描边字（星球名，主题色 22% 描边、透明填充），放在左下角，和地平线一起构成空态画面。
- 等宽字体只用于代码、路径、id、哈希和遥测 meta。

### S7 声音

现有 `SoundFX`（默认关闭，可开关）扩展为一套与转场对应的提示音：

| 事件 | 音色 |
|---|---|
| 锁定行星 | 现有 `select()` |
| 轨道切入 | 低频下滑 0.5s + 尾部高频短确认音 |
| 离轨 | 上滑 0.3s |
| 审批请求到达 | 两声短促中频 |
| Run 完成 | 上行三音（≈ 120ms） |
| Run 失败 | 单个低频钝音 |

音量不超过现有 `lock()`；窗口失焦时不播放。

### S8 星球专属小时刻（有趣，但都表达状态）

| 星球 | 时刻 | 表达的状态 |
|---|---|---|
| Sun | 所有子任务完成时，轨道条上的星球胶囊对齐成一线并闪一次光（"行星连珠"） | 整个任务完成 |
| Mercury | 地址栏的加载进度条是全系统最快的（200ms 一段），停止按钮按下时步骤刻度条瞬间"冻结"为灰色 | 已停止 |
| Venus | 专注模式下云带纹样缓慢覆盖两侧栏 | 进入专注 |
| Earth | 记录判决后，候选列上方的"月球"小圆绕基线一周（600ms） | 判决已记录 |
| Mars | 测试全部通过时状态栏扫过一道绿光 | 测试通过 |
| Jupiter | 选中记录时详情区的"关联"胶囊依次出现（30ms 错峰），像卫星入轨 | 关联加载完成 |
| Saturn | 计划触发时，时间轴上的点沿光环线"滑入"表格对应行 | 已触发并开始运行 |
| Uranus | 绑定校验通过时，虚线连线"冻结"成实线（冰）；失败时出现一个裂纹图形 | 绑定有效 / 无效 |
| Neptune | 生成进度表现为画布底部的一道波纹从左到右推进 | 生成中 |
| Pluto | 认可一条论断后，它的虚线认知标尺从左到右填实 | 未知 → 已证实 |

这些都是一次性、≤ 600ms，且在极简档全部关闭。

## 6. 特效档位与性能

| 档位 | 内容 | 默认条件 |
|---|---|---|
| 全效 | 全部 T0–T12、S2 呼吸、S3 流光 | 默认 |
| 标准 | 去掉镜头推进 / 冲击波 / 闪变 / 呼号 / 扫描线 / 呼吸；保留揭幕、面板淡入、状态反馈 | `SolarScene` 已有的 `degraded`（低帧率检测）触发时自动降到此档 |
| 极简 | 所有转场改为 150ms 淡入淡出；无流光、无 ping、无数字滚动 | `prefers-reduced-motion: reduce` 时强制 |

- 档位放在 Settings → Appearance，按 `settings.appearance.effects` 保存。
- 进入工作台后 WebGL 必须停止；工作台里的持续动画同屏最多两处（一处流光 + 呼吸点），都只动 opacity / 自定义属性角度。
- 闪变是单次、峰值 0.6 不透明度、300ms，不构成光敏风险。

## 7. 实施顺序

1. **tokens**：§3 动效 tokens + S1 色板进 `tokens.css`；替换散写的 cubic-bezier。
2. **T1 / T2**：`TransitionLayer` + `SolarScene.insertion()`；这是"帅"的主要来源，先做。
3. **S3 / S4 / T8 / T9**：发光与锁定语言，让工作台"活"起来。
4. **S2 轨道地平线**：10 个星球表面渐变 + 辉光。
5. **S5 遥测**：接 RTT / 事件游标 / 运行数。
6. **T5 / T6 / T7 / T11 / T12**：随 Dock、审批托盘、Tab 组件一起做。
7. **S7 声音、S8 星球小时刻**：最后加。

每一步都要在原型里先对过手感（4× 慢放 + 1×），再进应用。

下面是一个 Python 的冒泡排序示例，包含一个小的优化：如果某一轮没有发生交换，就提前结束排序。

```python
def bubble_sort(arr):
    """
    对列表进行冒泡排序（原地排序）
    """
    n = len(arr)
    # 最多需要 n-1 轮比较
    for i in range(n - 1):
        swapped = False  # 本轮是否发生过交换
        # 每轮结束后，最大的元素会被放到最后，所以无需再比较已排序部分
        for j in range(n - 1 - i):
            if arr[j] > arr[j + 1]:
                arr[j], arr[j + 1] = arr[j + 1], arr[j]
                swapped = True
        # 如果本轮没有发生交换，说明已经有序
        if not swapped:
            break
    return arr


# 示例测试
if __name__ == "__main__":
    numbers = [64, 34, 25, 12, 22, 11, 90]
    print("排序前:", numbers)
    bubble_sort(numbers)
    print("排序后:", numbers)
```

输出结果为：

```text
排序前: [64, 34, 25, 12, 22, 11, 90]
排序后: [11, 12, 22, 25, 34, 64, 90]
```

该算法的时间复杂度为 O(n²)，空间复杂度为 O(1)。
